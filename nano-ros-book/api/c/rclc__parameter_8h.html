Detailed Description

The C parameter server: rclc's API over the executor's store.

RFC-0105 / phase-491. ONE parameter family for C, under rclc's own names and at rclc's include path, so a ported #include <rclc_parameter/rclc_parameter.h> finds it. Every parameter declared here is served by the six rcl_interfaces services (ros2 param list/get/set/describe/dump/load).

What differs from upstream rclc, and why (RFC-0105 "bounded envelope"):

  • Nothing here allocates. The store is the executor's, sized at build time (NROS_MAX_PARAMETERS); max_params is a per-node quota inside it.
  • The node must be bound to an executor (nros_executor_node_init) before rclc_parameter_server_init_*; otherwise RCL_RET_NOT_INIT.
  • Local typed sets fire the callback and skip read-only and range checks, as rclc's do. REMOTE sets enforce read-only AND the range rclc only advertises (rclcpp's behaviour).
  • Parameter has rosidl's member paths (p->name.data, p->value.type, p->value.integer_value, ...) but is not a rosidl ABI type; there are no rcl_interfaces__msg__Parameter__init/fini. Its pointers are valid only for the duration of the callback. A scalar string_value is NUL-terminated; array elements, including a string array's, are not — read size.
  • notify_changed_over_dds is accepted; /parameter_events publication lands with phase-491 W3.

Calling context: the executor's task only, never an ISR. Like rclc, nothing here takes a lock.

Types are spelled with nano-ros's names (nros_ret_t, struct nros_node_t, struct nros_executor_t); <nros/rcl_compat.h> makes rcl_ret_t, rcl_node_t, rclc_executor_t and the RCL_RET_* codes the same types, so a ported file that includes it compiles unchanged. phase-492 makes the rcl spellings primary across the C API.

◆ rclc_parameter_callback_t

typedef bool(* rclc_parameter_callback_t) (const Parameter *old_param, const Parameter *new_param, void *context)

rclc's callback: old_param NULL when the write creates the parameter, new_param NULL when it deletes it; false refuses. Fired by local typed sets, remote sets, remote deletes (NOT_SET) and remote creations of an undeclared name — not by rclc_add_parameter or a local rclc_delete_parameter. While it runs, every mutating call on its server returns RCLC_PARAMETER_DISABLED_ON_CALLBACK.
