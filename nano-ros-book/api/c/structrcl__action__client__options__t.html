◆ sched_context

rclc_sched_context_id_t rcl_action_client_options_t::sched_context

Scheduling-context slot to bind the action client's executor handle to. 0 = inherit the executor / Node default. A non-zero value must be an id from rclc_executor_create_sched_context; the bind is applied by rclc_executor_attach_action_client once the handle exists. No effect on the L1 polling path.
