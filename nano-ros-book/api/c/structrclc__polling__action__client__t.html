Detailed Description

An action client the CALLER drives, with no executor (phase-487 W4).

The C counterpart of C++'s nros::PollingActionClient<A>. _opaque holds an ActionClientCore from rclc_polling_action_client_init until rclc_polling_action_client_fini. Zero-initialised is UNINITIALIZED. Until phase-487 it was the NROS_ACTION_CLIENT_STATE_POLLING state of rcl_action_client_t.
