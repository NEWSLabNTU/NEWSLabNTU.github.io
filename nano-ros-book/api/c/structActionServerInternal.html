Detailed Description

The arena handle, filled in by executor registration.

handle was Option<ActionServerRawHandle> previously; now it is always present, with the sentinel INVALID_ENTRY_INDEX indicating "not registered yet". Use is_handle_set() to check.

phase-487 W4 — this used to carry a SECOND copy of the server's callback record (c_goal_callback, c_cancel_callback, c_accepted_callback, c_context) plus a server_ptr back to the struct that contains it, so the trampolines could take &_internal as their context. The trampolines take the server itself now and read the one record it already has.
