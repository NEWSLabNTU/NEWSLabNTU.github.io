Detailed Description

Message type descriptor: what ROSIDL_GET_MSG_TYPE_SUPPORT(pkg, msg, Name) yields.

The generated <pkg>__msg__<Name>__nros_type is a static const of this type in read-only memory. It carries the type's NAME and HASH (what the RMW needs to create an entity) and, since phase-492 W8 (RFC-0089 "`ROSIDL_GET_*_TYPE_SUPPORT` adopted as a pass-through"), its CODEC, so rcl_publish and rclc_executor_add_subscription_with_context work on the generated struct with rclc's arguments. It is NOT rosidl's rosidl_message_type_support_t, which stays undeclared: that struct's members (typesupport_identifier, data, func) are a dispatcher this descriptor does not have.
