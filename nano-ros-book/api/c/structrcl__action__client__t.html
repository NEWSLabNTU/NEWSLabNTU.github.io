Detailed Description

An action client the executor dispatches.

phase-487 W4 (RFC-0096 D9, the C half): the executor arena owns the channels and buffers; this struct holds the arena handle (_internal), the registration description and the callback record the arena's trampolines read, as the C++ action client does. A client the caller drives itself is a [rclc_polling_action_client_t].
