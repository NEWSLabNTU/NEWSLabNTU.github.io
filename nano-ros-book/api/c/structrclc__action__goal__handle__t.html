Detailed Description

rclc's rclc_action_goal_handle_t (phase-515 C4b): one goal of an rclc action server, handed to the goal and cancel callbacks and back to rclc_action_send_result / rclc_action_publish_feedback.

ADOPT-BOUNDED: rclc's members a server reads are here with rclc's names and types (status, goal_id, ros_goal_request, goal_accepted, goal_cancelled, action_server). ros_goal_request is a void * (rclc types it struct Generic_SendGoal_Request *; both are cast to the user's <Action>_SendGoal_Request *). rclc's request headers and its action-client member are not: the runtime answers each request itself, and rclc's typed action client is not ported. The handles live in the server (at most NROS_MAX_CONCURRENT_GOALS), not in executor-allocated memory.
