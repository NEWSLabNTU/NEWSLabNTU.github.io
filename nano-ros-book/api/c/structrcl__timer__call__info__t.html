Detailed Description

When a timer activation was due and when it ran — Jazzy rcl's rcl_timer_call_info_t (issue 1974), same name, same two fields.

Both are rcl_time_point_value_t nanoseconds on the TIMER'S clock: the clock it was initialised on (rcl_timer_init*), or the platform steady clock for a wall timer. actual_call_time >= expected_call_time always; the difference is the activation's lateness.

The executor's timer dispatcher is the one producer (nros_node::TimerCallInfo); this is a field-for-field copy of it, handed to an rclc_timer_callback_with_info_t for the duration of the call.
