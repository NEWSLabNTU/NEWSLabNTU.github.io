Detailed Description

A service client the executor dispatches (rclc's rcl_client_t).

phase-487 W2 (RFC-0096 D9, the C half): the arena entry owns the client, its reply buffer, the response callback and its context. This struct keeps the arena handle (_internal, with the rclc_client_call timeout) and the description the registration reads. Before W2 the arena entry's callback was a trampoline that read the callback out of THIS struct, a back-reference that made a late reply after rcl_client_fini a use-after-free (issue 1631); the entry now holds the user's callback directly. A client the caller drives itself is a [rclc_polling_client_t].
