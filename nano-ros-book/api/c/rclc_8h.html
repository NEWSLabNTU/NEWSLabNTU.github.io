Detailed Description

Umbrella header for the nano-ros C API, at upstream's path.

Including this single header provides the whole C API: rclc's and rcl's names, the nano-ros-only parts (RCLC_C_COMPONENT, RCLC_CHECK_RET, RCLC_LOG_*), and the rcl spellings of the return codes. Every other upstream-path header (<rclc/node.h>, <rcl/rcl.h>, ...) includes it. Headers under rclc/detail/ are internal (phase-501).
