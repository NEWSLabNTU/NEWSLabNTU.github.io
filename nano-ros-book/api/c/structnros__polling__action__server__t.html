Detailed Description

An action server the CALLER drives, with no executor (phase-487 W4).

The C counterpart of C++'s nros::PollingActionServer<A>. _opaque holds an ActionServerCore (five channels, goal table, buffers) from nros_polling_action_server_init until nros_polling_action_server_fini. Zero-initialised is UNINITIALIZED. Until phase-487 it was the NROS_ACTION_SERVER_STATE_POLLING state of nros_action_server_t.
