37// phase-303 W4 (#0267) — XCDR2 DHEADER delimiters. Under XCDR1 (humble) these
38// are no-ops returning -1 (mark) / 0. Under XCDR2 (iron/jazzy+) begin reserves a
39// 4-byte DHEADER (returns its offset as the mark); end backpatches it with the
40// member-block size. Generated `_serialize_inline` / `_deserialize_inline` wrap
41// every struct so appendable types carry a DHEADER matching a modern ROS 2 peer.
42// begin returns >=0 mark or -1 (XCDR1) on success, -2 on error.
