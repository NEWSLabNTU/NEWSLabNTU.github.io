Detailed Description

Issue 1913 — the hash each of an action's five endpoints is keyed on.

An Iron+ rmw_zenoh_cpp peer keys every endpoint on its OWN type (the SendGoal / GetResult services, action_msgs/srv/CancelGoal, the FeedbackMessage, action_msgs/msg/GoalStatusArray), so the single type_hash an action carried matched none of them. A NULL member means "use `type_hash`", which is what C generated by an older nros gets: designated initializers zero this trailing field. Members must point at strings with STATIC storage — the generated type support's literals — because a server or client keeps the pointers from init until it registers.
