Detailed Description

A service server the executor dispatches (rclc's rcl_service_t).

phase-487 W2 (RFC-0096 D9, the C half): the arena entry owns the server, its request and reply buffers, the callback and its context. This struct keeps the arena handle (_internal) and the description the registration reads. A server the caller drains itself is a [rclc_polling_service_t].
