Detailed Description

A service server the CALLER drains, with no executor (phase-487 W2).

The C counterpart of C++'s nros::PollService<S>. Nothing dispatches it, so it has no arena slot: _opaque holds a RawServiceServer from rclc_polling_service_init until rclc_polling_service_fini. Zero-initialised is UNINITIALIZED. Until phase-487 it was the NROS_SERVICE_STATE_POLLING state of rcl_service_t, which made every dispatched server carry this storage unused.
