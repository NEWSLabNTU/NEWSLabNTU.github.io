Detailed Description

Error-check convenience macros for the nros C API.

Wraps the common "call returns rcl_ret_t; on failure log and bail" pattern in one-liners so example main()s and user code don't open-code 4-line check blocks at every API site.

Pattern parity with rclc:

  • RCLC_CHECK(call) — fatal: log and return from the enclosing void function.
  • RCLC_SOFTCHECK(call) — non-fatal: log and continue.

The macros log file:line, the literal call text, and the integer return code. Issue 0332 — the default logger is printf ONLY on a hosted target (__STDC_HOSTED__) or when RCLC_CHECK_STDIO is defined; on a freestanding embedded target it defaults to a no-op, so a no_std C node does not silently pull <stdio.h> into every TU.

Override the log function by defining RCLC_CHECK_LOG(file, line, expr, ret) before including this header (e.g. to route through a board's UART, RTT, or nros-log), or define RCLC_CHECK_STDIO to force the printf form on a freestanding target.
