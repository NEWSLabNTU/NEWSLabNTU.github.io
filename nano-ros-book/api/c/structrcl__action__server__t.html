Detailed Description

An action server the executor dispatches.

phase-487 W4 (RFC-0096 D9, the C half): the executor arena owns the five channels, the goal table and every buffer; this struct holds the arena handle (_internal), the registration description and the one callback record, which the arena's trampolines read with this struct as their context. That record stays here, as the C++ action server's does (phase-456 W3b-ii refused moving it into the arena: the trampolines translate the ABI and reframe the goal payload). A server the caller drives itself is a [rclc_polling_action_server_t].

rclc's rclc_action_server_t (phase-515 C4b). One struct serves rcl's spelling and rclc's: rclc_action_server_init_default and rclc_executor_add_action_server take this.

struct rcl_action_server_options_t rclc_action_server_t::options

Phase 189.M3.3.b — scheduling-context slot to bind the action server's executor handle to (the goal-service slot; governs the action's callback dispatch). 0 = inherit the executor / Node default; set via rclc_action_server_init_with_options.
