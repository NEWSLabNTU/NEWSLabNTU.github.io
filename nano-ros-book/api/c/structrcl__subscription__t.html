Detailed Description

A subscription the executor dispatches (rclc's rcl_subscription_t).

phase-487 W1 (RFC-0096 D9, the C amendment): an entity the executor dispatches is owned by the executor. The subscriber, its receive buffer, the callback and its context all live in the executor arena's entry, and this struct holds the arena handle (handle_id, _executor) plus the DESCRIPTION the registration needs. The description has to be here because rclc's order is init first, rclc_executor_add_* second: at init there is no executor to hold it yet.

Before phase-487 this struct also carried the callback, the context and the polled form's subscriber storage (_opaque). On the dispatched road none of the three was read after registration, because the arena keeps its own copies. A subscription the caller drains itself is a [rclc_polling_subscription_t].
