Detailed Description

A service client the CALLER drives, with no executor (phase-487 W2).

The C counterpart of C++'s nros::PollClient<S>. _opaque holds a RawServiceClient from nros_polling_client_init until nros_polling_client_fini. Zero-initialised is UNINITIALIZED. Until phase-487 it was the NROS_CLIENT_STATE_POLLING state of nros_client_t.
