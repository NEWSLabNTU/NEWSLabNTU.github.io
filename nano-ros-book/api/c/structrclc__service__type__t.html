Detailed Description

Service type descriptor: what ROSIDL_GET_SRV_TYPE_SUPPORT(pkg, srv, Name) yields (phase-492 W8).

Generated as <pkg>__srv__<Name>__nros_type. The four codec slots are the request and response parts' serialisers, with the [rclc_message_serialize_fn_t] / [rclc_message_deserialize_fn_t] contracts; NULL where the descriptor was built from names alone.
