Detailed Description

Matched payload — NROS_RMW_EVENT_PUBLICATION_MATCHED / NROS_RMW_EVENT_SUBSCRIPTION_MATCHED. Upstream rmw_matched_status_t (Iron+), same four fields in the same order.

Width is the one deviation: upstream's three counts are size_t; ours are uint32_t, like every other count in this header, so the union keeps one layout on 32- and 64-bit targets. current_count_change is int32_t on both sides.
