Detailed Description

Borrow-shaped union the backend supplies to the registered callback. The kind argument selects which member is valid.

Members are APPENDED (issue 1972 grew it from 8 to 16 bytes). A caller owns the union it hands *_take_event, so a backend built against the older, smaller header writes within the larger one.
