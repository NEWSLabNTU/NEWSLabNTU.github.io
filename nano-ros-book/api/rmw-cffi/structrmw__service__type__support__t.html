Detailed Description

A service type's identity. See rmw_message_type_support_t.

Separate from the message form for the reason upstream separates them: rosidl_service_type_support_t and rosidl_message_type_support_t are distinct types there, and collapsing them here would let a service type be passed where a message type is required with no diagnostic.
