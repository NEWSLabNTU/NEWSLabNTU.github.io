Detailed Description

Per-request metadata — upstream rmw_service_info_t, field for field.

Issue 2081. Filled by take_request_with_info. As in rmw_message_info_t, a field the backend cannot report is ZERO: a timestamp of 0 means "not stamped", and an all-zero request_id.writer_guid means the request id is not reported. The runtime turns each into None, never into a value.
