Expand description

rclrs’s IntoNodeOptions: anything a node can be created from — a bare name ("talker") or a full NodeOptions — so executor.create_node("talker") and executor.create_node("talker".namespace("/robot")) read as they do in rclrs.

ADOPT-BOUNDED: rclrs’s other builder steps (arguments, use_global_arguments, enable_rosout, start_parameter_services, clock_type, clock_qos) configure what is fixed at build time here (RFC-0045), so they are absent and a call to one is a compile error.
