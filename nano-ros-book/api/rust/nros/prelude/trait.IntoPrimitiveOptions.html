Expand description

rclrs’s IntoPrimitiveOptions: anything an entity can be created from — a bare name or a PrimitiveOptions — with rclrs’s QoS steps chained onto it ("chatter".keep_last(10).reliable()).

ADOPT-BOUNDED: see PrimitiveOptions for the duration-valued steps.
