Struct RunToCompletionLevels

Expand description

Levels that RUN TO COMPLETION: one pass per wake, never a blocking wait.

An RTIC level is a software task at its own hardware priority. A level that parked on a timed wait, as a threaded RTOS’s level does, would hold its priority and starve every level below it, the boot level’s transport included. So each non-boot level’s task does ONE band pass (LevelCore::spin_level_once with a zero timeout) per wake, and two things wake it:

  • an arrival in its band, through the level’s BandWaiter, whose wake the image points at “spawn this level’s task” (LevelCore::open_level_with);
  • its band’s next timer, through ONE board one-shot armed at the earliest deadline over the non-boot levels (Self::rearm). Without it a higher band’s due timer would wait out the boot level’s park, which is bounded by the boot band’s own timers only.

A band’s deadline is read at the end of that level’s own pass, the one moment it is exact (a band’s timers are credited their elapsed time by its own passes), and kept as an absolute time per level.

A const static: the image’s boot task Self::installs the core once, before any level runs, and every level and the wake interrupt read it after.
