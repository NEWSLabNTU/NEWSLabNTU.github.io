Struct LevelCore

pub struct LevelCore { /* private fields */ }
Expand description

The core’s runtime, shared by every level of the image. Copy: each level’s thread carries the handle.

pub unsafe fn new( runtime: ExecutorNodeRuntime, n_levels: u8, boot_level: u8, mutex: *mut c_void, lock: ExecLockFn, unlock: ExecLockFn, thread_id: ThreadIdFn, ) -> Result<Self, LevelError>

Make runtime the core’s level runtime (leaked for the image’s life).

n_levels is the image’s level count and boot_level the level of the calling thread. With more than one level, mutex must be an initialised recursive priority-inheriting mutex that lock / unlock take and give and thread_id must name the calling thread: the executor carries them so every pass releases the lock around its callbacks and the levels preempt each other on one executor.

§Safety

Called before any second thread can reach the runtime. mutex lives for the image’s life; thread_id is equal on one thread and distinct across live threads.

pub unsafe fn open_level( &self, level: u8, ) -> Result<&'static mut BandWorker, LevelError>

Open level level on the calling thread: its worker (leaked with the level) attached to the executor’s arrival routing and the level made the registering one. Returns the worker the thread’s passes use.

§Safety

Called once per level, on the level’s own thread.

Source

pub unsafe fn spin_level_once(&self, worker: &mut BandWorker, timeout: Duration)

One pass of a spawned level’s worker: it parks (its waiter, the lock released) for at most timeout or until its band’s next timer or an arrival, then runs its band’s ready callbacks and (issue 2020) the ticks of the components its level registered – the executor’s enrolled ones inside the band pass, the runtime’s own after it, the lock held.

§Safety

worker is the calling thread’s, from Self::open_level.

Source

pub unsafe fn spin_boot_once(&self, timeout: Duration)

One pass of the boot level: the executor’s own worker (transport, executor-wide chores), then the boot level’s components’ ticks, the lock held except around each callback.

§Safety

Called from the boot level’s thread only.
