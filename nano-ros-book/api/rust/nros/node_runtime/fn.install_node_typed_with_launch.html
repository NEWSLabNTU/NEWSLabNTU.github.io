Phase 305 W3 (issue 0255) — same as install_node_typed_with_node_identity but also carries the launch <remap from= to=/> rules nros::main! baked for this component (RuntimeCtx::remaps). ExecutorSink::create_entity applies them (plus ~/relative expansion) before any entity name reaches the wire. All slices must outlive the call ('static promoted in the macro emit).

§Safety

executor must be the live *mut Executor<'static> handle a typed entry passes, valid for the call.
