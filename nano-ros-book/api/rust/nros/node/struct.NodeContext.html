Struct NodeContext 

Source 
pub struct NodeContext<'a> { /* private fields */ }
Expand description

Node declaration context — what a component’s register receives.

It creates REAL nodes. create_node returns a crate::Node, the same type Executor::create_node gives a standalone program, so a component’s node code and a program’s node code are one code. The component-only declarations are the DeclarativeNode methods on that node.

pub fn create_node<'o>( &mut self, options: impl IntoNodeOptions<'o>, ) -> NodeResult<Node<'_, 'static>>

Create this component’s node — rclrs’s executor.create_node(options).

The node’s name is the launch file’s when it names one, otherwise options.name, which is also the component-stable node id the declarations are keyed on.

Takes rclrs’s impl IntoNodeOptions, so context.create_node("talker") reads as rclrs does. Unlike the executor’s, a component’s options are applied as written.
