Expand description

The ROS graph queries a component context forwards: the fourteen the executor’s Node has, which are rclrs’s names, with the executor’s visitor signatures. Object-safe, so a context holds it as &mut dyn GraphQuery.

Every answer is what has been DISCOVERED and never blocks: an empty visit or a low count is “not seen yet”, never proof of absence, and Err(Transport(Unsupported)) from a backend with no graph is a different answer from empty.

An implementor reaches the executor’s session for the length of ONE call and keeps nothing: no session pointer outlives the query.
