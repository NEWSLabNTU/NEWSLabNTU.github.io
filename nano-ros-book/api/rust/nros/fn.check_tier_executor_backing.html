Gated like the module it names (has_rmw + alloc in nros-node). issue 1571 — the ONE refusal every board’s run_tiers makes before it opens anything: n_tiers tiers run, one on the boot executor, so n_tiers - 1 must each find a slot. Checked up front rather than at each spawn, so a short block never leaves a half-spawned tier chain.
