The Rust face of <nros/platform_can.h>: a CAN frame driver handle over the five generated nros_platform_can_* declarations.

The definitions come from whichever backend the image links (Zephyr’s CAN API, SocketCAN, a board package’s driver, or nros-can-mock); this module only calls them. send and send_fd are one C call: send_fd sets NROS_PLATFORM_CAN_FLAG_FD on a copy of the frame.

An open CAN device. It borrows its storage, so the storage cannot move while the handle is open (a backend may keep self-referencing kernel objects in it); dropping the handle closes it.
