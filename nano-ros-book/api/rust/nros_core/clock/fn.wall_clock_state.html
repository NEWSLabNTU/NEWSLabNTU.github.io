pub fn wall_clock_state() -> Option<WallClockState>
Expand description

The wall clock’s state from the linked port, or None when this build has no port to ask (no platform-clock), the same condition under which Clock::system falls back to its counter.

Every port DEFINES nros_platform_wall_clock_state; a port that does not fails to link, naming the symbol.
