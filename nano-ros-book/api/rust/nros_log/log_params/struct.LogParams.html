Struct LogParams 

Source 
pub struct LogParams<'a> { /* private fields */ }
Expand description

rclrs’s LogParams: the logger plus the modifiers one record carries.

ADOPT-BOUNDED: it borrows the Logger (LogParams<'a>) where rclrs’s owns a logger name. Build one through ToLogParams.
