pub fn add_sink(sink: &'static dyn LogSink) -> bool
Expand description

Append sink to the sinks every record is delivered to.

Returns false when MAX_ADDED_SINKS are already registered — the sink is NOT installed, and the caller is expected to say so rather than carry on as if it were.

Records raised before any sink existed are replayed into sink here, the same way init replays them, so the first sink to arrive still sees the boot story regardless of which of the two calls installed it.
