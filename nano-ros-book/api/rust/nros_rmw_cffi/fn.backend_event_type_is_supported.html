Issue 1978 — THE one answer to “can this backend carry event kind?”, for every caller behind the C ABI: the per-entity supports_event of CffiPublisher and CffiSubscription both ask it, so the per-entity answer can never claim a kind the backend-level event_type_is_supported slot denies.

A kind is supported when the backend has an event PATH for its side (*_event_init callback or *_take_event poll, issue 1164) AND, where the backend fills event_type_is_supported, that slot says yes. A NULL event_type_is_supported falls back to the path alone — slot granularity, which was the whole answer before the slot existed and is still the honest one for a backend that states nothing per kind.
