Issue 1190 – the arena derivation’s MODEL, as the consts it summed.

Emitted rather than retyped: executor::arena asserts that each term is an UPPER BOUND on the entry types it stands for, and it can only do that against the numbers the derivation actually used. The previous arrangement had the_default_derivation_is_unchanged retyping six of them, which is a second copy that agrees until one side moves.
