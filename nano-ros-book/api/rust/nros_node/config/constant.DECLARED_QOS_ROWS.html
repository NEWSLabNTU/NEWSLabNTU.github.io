phase-454 W10 – the QoS this image’s system DECLARED, per subscription: its history DEPTH and (issue 1256) its RELIABILITY and DURABILITY, each None where nobody stated it. Read by declared_qos::check / declared_qos::honour at every subscription registration (NROS_ENTITY_DECLARED_DEPTHS + the sizing descriptor).

Both TYPE spellings appear per declared endpoint – the ROS pkg/msg/Name and the DDS-mangled pkg::msg::dds_::Name_ – because which one a generated message class carries is a property of the codegen that produced it.

None is “nobody declared”, never “declared zero”: an image with no contract sidecar checks nothing and behaves exactly as it did before.
