Fit a profile the RUNTIME chose for one of its own endpoints (/rosout, /parameter_events, the lifecycle services and transition_event) to what supported honours, and say once, per endpoint, which policies that dropped.

The rule is QoSProfile::fit_to_supported’s: a runtime profile is a preference, so a policy the backend cannot carry steps down instead of refusing the endpoint. Only the runtime’s own base profile comes here. Whatever a person wrote and is folded on afterwards (a per-topic override, a declared contract, an application profile) is still validated and refused naming the policy.
