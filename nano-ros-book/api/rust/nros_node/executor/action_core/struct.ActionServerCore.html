Expand description

Type-agnostic action server core handling the raw-bytes protocol.

Manages active goal tracking (GoalUuid + status), completed result storage in a fixed-size slab, and all CDR framing for the action protocol.

The typed ActionServer wraps this and adds A::Goal / A::Feedback / A::Result (de)serialization.
