Struct ExecGuard

pub struct ExecGuard { /* private fields */ }
Expand description

Holds the executor’s lock for its own lifetime: taken at ExecGuard::acquire, given at drop. With no lock installed it holds nothing.

Source

pub unsafe fn acquire(exec: *const Executor<'_>) -> Self

Take the lock installed on the executor at exec, BEFORE any reference to that executor exists – the order that keeps a second thread’s reference from overlapping this one.

§Safety

exec points at a live, initialised executor. Its lock field is read without a reference: it is written only while no second thread can reach the executor (super::Executor::set_exec_lock).
