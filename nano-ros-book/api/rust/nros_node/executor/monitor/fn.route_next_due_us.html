pub fn route_next_due_us(table: &[MonitorSpec], now_us: u64) -> Option<u64>
Expand description

phase-503 – time from now to the earliest deadline of a pending supervised route, in microseconds (0 when one is already due), or None when no supervised route is waiting. This is the executor’s wake source for the rule, and what a port’s independent timer (MECHANISM_TIMER) arms on.

The due time is take + route_deadline_ms, derived from the stored take rather than kept in a second cell: both are the clock’s low 32 bits, so the difference is exact across a wrap as long as a route waits less than ~71 minutes, and a supervised one is reported long before that.
