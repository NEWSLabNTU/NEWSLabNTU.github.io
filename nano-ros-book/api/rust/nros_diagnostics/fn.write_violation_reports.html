phase-474 I7 – several violation reports COALESCED into one DiagnosticArray: one status per (rule, fqn, measured, declared), in order, each byte-identical to the status write_violation_report sends for it alone. The executor queues verdicts and hands them over off the judged dispatch; on a slow link one message for several verdicts is what keeps the report from costing a tick per verdict.

At most four statuses (the generated type’s capacity) are meaningful to an nros subscriber; a caller passing more is refused with BufferTooSmall before anything is written.
