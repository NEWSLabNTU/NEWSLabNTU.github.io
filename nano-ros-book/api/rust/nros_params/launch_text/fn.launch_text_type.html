pub fn launch_text_type(text: &str) -> Result<LaunchTextType, LaunchTextError>
Expand description

The type ParameterValue::assign_launch_text would give text, without filling a value and without a capacity check.

For a BUILD that sizes the store before any value exists: a launch seed takes a slot of this type, so the host counts it by the device’s own reading rather than a second one that could disagree. No capacity, because the build is what decides the capacities: a seed too long for today’s store is exactly what the count must grow it for, not a reason to skip it. Err only where the device refuses the text whatever the capacity: an empty list, a mixed list, a broken quote.
