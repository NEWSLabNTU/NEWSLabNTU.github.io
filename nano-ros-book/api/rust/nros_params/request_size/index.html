Module request_size 

Source
Expand description

What a parameter-service REQUEST costs on the wire, from a node’s declared parameter shape and the parameter store’s capacities. The ONE formula for the request side. nros-node’s param_sizing::node_bound prices every parameter-service message with it (the inbox slot and the build-time check that a stated slot fits), and nros build prices the same requests from the contract to suggest a slot size before any build script runs. Two readers, one function: a second spelling of this arithmetic is how one formula’s inputs drift apart.

Pure arithmetic over counts. It reads no MAX_* of this crate, so a caller that has not built the store (the CLI) passes the capacities it would build with.
