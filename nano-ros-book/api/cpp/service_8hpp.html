Detailed Description

rclcpp::Service<S> — the arena-registered (callback-style) service server, and Service<S>::SharedPtr = rclcpp::ServiceHandle<S>.

The POLL-style server — caller-owned storage, take_request() / send_response() — is rclcpp::PollService<S> in rclcpp/polling_service.hpp since phase-456 W5. See there for why the two are separate types.
