Detailed Description

rclcpp::Service<S> — the arena-registered (callback-style) service server, and Service<S>::SharedPtr = rclcpp::ServiceHandle<S>.

The POLL-style server — caller-owned storage, take_request() / send_response() — is rclcpp::PollService<S> in rclcpp/polling_service.hpp since phase-456 W5. See there for why the two are separate types.

◆ rmw_request_id_t

typedef struct rmw_request_id_t rmw_request_id_t

rmw_request_id_t — upstream's request header (<rmw/types.h>): who sent a service request (the client's writer GUID) and the sequence number it assigned. Upstream's three-argument service handler receives it. Issue 2081 fills it from the backend's report; a backend that reports no id leaves it all zero. The same struct, under the same guard, as <nros/rmw_entity.h> and <rclc/detail/request_id.h>.
