Detailed Description

Callback dispatch, timers, guard conditions, futures, streams.

rclcpp::Executor polls the transport and dispatches ready callbacks. rclcpp::Timer fires on a periodic interval; rclcpp::GuardCondition is a cross-thread wake source. rclcpp::Future<T> and rclcpp::Stream<T> are the futures/streams returned by service and action clients.
