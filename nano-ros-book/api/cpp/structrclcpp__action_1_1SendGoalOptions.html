Detailed Description

Options for async goal sending (mirrors rclcpp SendGoalOptions).

Installed on the CLIENT with set_callbacks(), not passed per goal. Callbacks are invoked during spin_once() when the corresponding response arrives. All callbacks receive the context pointer for user state.

Issue 2015 — on a HOSTED build it ALSO carries upstream's three per-goal fields, goal_response_callback / feedback_callback / result_callback, taking upstream's shapes (GoalHandle::SharedPtr, std::shared_ptr<const Feedback>, const WrappedResult&). Those are read by async_send_goal, per goal, as upstream does; the raw pointers are read by set_callbacks, per client. A freestanding build refuses an assignment to the upstream fields.
