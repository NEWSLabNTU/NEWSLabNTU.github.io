Detailed Description

template<typename T, size_t Cap = ::rclcpp::rx_buffer_capacity<T>::value>
class rclcpp::Future< T, Cap >

Single-shot deferred result for request/response operations.

Returned by PollClient<S>::send_request (phase-456 W9; it was Client<S>::send_request before the split). The future is consumed when the result is taken – move-only, single-shot.

Usage:

auto fut = client.send_request(req);
ResponseType resp;
NROS_TRY(fut.wait(executor.handle(), 5000, resp));
NROS_TRY

Template Parameters
CapBytes the RECEIVE buffer holds. Defaults to T's own derived bound where it has one, and to the legacy T::SERIALIZED_SIZE_MAX estimate where it does not. The _sized escape hatches are Client::send_request_sized and ActionClient::get_result_future_sized, which hand back a Future<T, N> (issue 0964). This buffer IS the capacity: under-sizing it truncates the reply.
