Detailed Description

template<typename A>
struct rclcpp_action::detail::ServerUpstream< A >

Issue 2015 — binds upstream's three create_server callbacks onto a Server<A> through its existing goal / cancel / accepted slots, and keeps each live goal's message so its handle can answer get_goal(). Hosted only; on a freestanding build every member is a no-op and nothing calls bind.
