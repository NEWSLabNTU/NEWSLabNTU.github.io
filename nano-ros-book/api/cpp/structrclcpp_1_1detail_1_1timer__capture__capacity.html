Detailed Description

template<typename F>
struct rclcpp::detail::timer_capture_capacity< F >

The capture capacity a timer adapter needs: the usual knob, except for a callable that is ITSELF an InplaceFn (a TimerInfoCallbackType variable passed by name), whose size is the knob plus two pointers by construction. The arena copies any length, so this only stops that one shape from tripping the capacity static_assert meant for oversized lambdas.
