Detailed Description

rclcpp::Context (phase-488) — a VIEW of one executor's lifetime: its pre- and on-shutdown hooks (issue 0790) and whether it is still running.

Upstream's context owns the rcl init state and is reached through a shared_ptr. nano-ros's executor owns that state, so this names one by its handle: SharedPtr is the view itself and -> reaches it, so rclcpp::Context::SharedPtr c = node->get_node_base_interface()->get_context(); c->add_pre_shutdown_callback(cb) spells as upstream's does. The hooks share the executor's fixed table (NROS_EXECUTOR_MAX_SHUTDOWN_CBS, default 2): a full table returns an INVALID handle on the std surface, where upstream would allocate.
