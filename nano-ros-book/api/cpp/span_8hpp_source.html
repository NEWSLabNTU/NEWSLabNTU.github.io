1// nros-cpp: Lightweight non-owning view types
2//
3// Provides rclcpp::Span<T> and rclcpp::StringView as zero-overhead alternatives
4// to std::span (C++20) and std::string_view (C++17). Compatible with GCC 5+,
5// Clang 3.5+, and all embedded toolchains.
6//
7// Written in the freestanding C++14 subset, which is a property of this
8// FILE and not the project's minimum: nano-ros declares C++17 (issue 1118 —
9// `target_compile_features(nros-cpp-headers INTERFACE cxx_std_17)`), because
10// that is what ROS 2 Humble's own `rclcpp` exports (phase-426 W4 retired the
11// construct-specific half of this claim: `component_node.hpp`'s `if constexpr`
12// left with `adopt_launch_seed_`). `just check cpp` still parses
13// this header at `-std=c++14 -ffreestanding`, so the subset is enforced and
14// not merely claimed.
15//
16// These types are used by generated borrowed message structs to reference
17// variable-length data in the CDR receive buffer without copying.
