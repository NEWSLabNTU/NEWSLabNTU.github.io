◆ namespace_()

NodeBuilder & rclcpp::NodeBuilder::namespace_ ( const char * ns)
inline

Set the Node's namespace (mirrors rclcpp::Node's ctor). Empty or nullptr leaves it UNSET, and an unset namespace INHERITS the executor's — the same vocabulary rmw(), locator() and domain_id() above already use for this struct's other fields. Pass "/" to place the Node at the root explicitly (issue 1473).

◆ rmw()

NodeBuilder & rclcpp::NodeBuilder::rmw ( const char * name)

Bind this Node to the named RMW backend. The name must match a backend registered with nros_rmw_cffi_register_named (or its auto-ctor equivalent). Empty/nullptr selects the first- registered backend — the single-backend convenience path.
