◆ by_goal

bool rclcpp::detail::PendingLink::by_goal = false

Issue 2011 — an ACTION future is keyed by its GOAL instead of a sequence id: an action client's acceptance and result arrive attributed to a goal (the Rust core correlates each sub-client's replies by id, issue 2009), so the goal is the key a reply carries up here.
