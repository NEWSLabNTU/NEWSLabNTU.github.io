Detailed Description

rclcpp::executors::SingleThreadedExecutor — phase-488. ADOPT-BOUNDED.

A FACADE over the process executor, which is what every rclcpp::Node already lives on: there is one session per image (issue 0465) and a node's entities are created in that executor's arena when the node is constructed (RFC-0002). So the three lines a stock main writes keep their meaning — 

rclcpp::executors::SingleThreadedExecutor executor;
executor.add_node(node);
executor.spin();

— with add_node CHECKING the attachment that construction already made rather than making one. The bound, stated: there is no second executor to build, so two of these are the same executor; add_node aborts, naming the node, when the node failed to create or was created on an explicit rclcpp::Executor instead (spinning this would never reach it); there is no remove_node, because arena registration is one-way (the cpp:Executor::add_node row). spin / spin_some are rclcpp::spin_in() / the process executor's spin_some.
