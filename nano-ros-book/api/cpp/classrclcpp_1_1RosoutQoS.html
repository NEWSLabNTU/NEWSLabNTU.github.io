Detailed Description

rcl_qos_profile_rosout_default — KEEP_LAST(1000), RELIABLE, TRANSIENT_LOCAL, lifespan 10 s. ADOPT.

ADOPT-BOUNDED on one point, and it is about the TOPIC, not the profile: the profile's four policies are transcribed exactly, but nano-ros publishes no /rosout topic (logging goes to nros_log's per-platform sink), so this names a profile you can apply to a topic of your own rather than one the runtime is already using.
