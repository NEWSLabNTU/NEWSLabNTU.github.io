Detailed Description

What timer_->... reaches on a [TimerHandle]: the operations a timer registration supports, over the same two words — phase-476 W2.

A separate type from the handle because ported code says BOTH timer_->reset() (restart the timer) and timer_.reset() (drop it), and upstream gives them different meanings. Behind one class, operator-> returning this would make the two spellings the same call.
