Detailed Description

rclcpp::Client<S> — the arena-registered (callback-style) service client, and Client<S>::SharedPtr = rclcpp::ClientHandle<S>.

The FUTURE-style client — caller-owned storage, send_request() / call() / wait_for_service() — is rclcpp::PollClient<S> in rclcpp/polling_client.hpp since phase-456 W9. See there for why the two are separate types.
