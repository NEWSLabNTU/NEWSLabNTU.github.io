Detailed Description

template<typename T, size_t N>
struct rclcpp::FixedSequence< T, N >

Fixed-capacity sequence container.

Wraps a uint32_t size + T data[N] pair with push/access methods. Memory layout is identical to struct { uint32_t size; T data[N]; }, so the type is C-ABI compatible with the runtime.

Usage:

rclcpp::FixedSequence<int32_t, 64> values;
values.push_back(42);
values.push_back(7);
for (uint32_t i = 0; i < values.length(); ++i) {
printf("values[%u] = %d\n", i, values[i]);
}

Upstream's bounded-sequence resize(n) (phase-488; Nav2 writes descriptor.floating_point_range.resize(1)). New elements are value-initialized. A length past the capacity is refused: the sequence is unchanged and the answer is false, where rosidl's BoundedVector throws std::length_error.
