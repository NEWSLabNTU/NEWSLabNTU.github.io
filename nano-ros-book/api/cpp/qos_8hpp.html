◆ rmw_qos_profile_t

typedef struct rmw_qos_profile_s rmw_qos_profile_t

Upstream's rmw_qos_profile_t (rmw/types.h): same fields, same order, same types. An aggregate, so upstream's brace initialisers compile.

The one addition is the conversion to rclcpp::QoS, which is what lets a profile reach a verb that takes QoS — Humble's create_service takes the struct, ours takes QoS. A profile carrying a SYSTEM_DEFAULT or UNKNOWN policy converts to a QoS carrying the same sentinel, exactly as a get_actual_qos() read-back does; no constant below carries one except liveliness, which every upstream profile leaves to the middleware.
