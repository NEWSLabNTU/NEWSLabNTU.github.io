Detailed Description

template<typename T>
struct rclcpp::Span< T >

Non-owning view over a contiguous sequence of T values.

Same semantics as std::span<const T>, without needing C++20 for it. The data pointer is valid only for the lifetime of the source buffer (typically the subscription callback scope).
