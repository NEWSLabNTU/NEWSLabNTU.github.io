1860// `ComponentNode` carried `Timer timers_[NROS_COMPONENT_MAX_TIMERS]` — 192
1861// unconditional bytes at the default depth of 8. Merging that onto `Node` would
1862// have charged every node in the tree for a pool most of them never touch, on
1863// targets chosen for having no memory to spare.
