Detailed Description

Service servers and clients (rclcpp::Service<S>, rclcpp::Client<S>).

S is a generated service type that exposes nested Request and Response types. Servers dispatch via the executor; clients return a rclcpp::Future<typename S::Response> from async_send_request.
